# FRAG - Module 1

This version is made for the current `create-expo-app` folder structure that uses `src/app`.

## Copy these files into your Expo project

```text
YOUR_EXPO_PROJECT/
├── src/
│   ├── app/
│   │   ├── index.tsx
│   │   └── _layout.tsx
│   └── constants/
│       └── styles.ts
├── assets/
│   └── images/
│       └── frag-logo.png
└── exercise.ts
```

If your Expo template already contains other example files inside `src/app`, you can delete them or leave them unused. The important route is `src/app/index.tsx`.

## Run

From the Expo project folder:

```bash
npm install
npx expo start --go -c
```

Scan the QR code with Expo Go.

## Module 1 requirements used in the app

- Custom functions
- Conditions
- `map()` loops
- TypeScript `type`
- TypeScript `interface`
- Array of objects
- Inline styles
- External styles
- React Native UI components
- Ionicons package
